# **Java-Data-Structures-Projects**



This repository contains a collection of Java projects focused on implementing core data structures as part of the curriculum of the Department of Information and Electronic Engineering at the International Hellenic University.



### **Academic Context**



Institution: International Hellenic University

Department: Information and Electronic Engineering

Course: Data Structures with Java



### **Implemented Data Structures**



Linear Structures: Arrays, Linked Lists (Singly/Doubly), Stacks, Queues



Hierarchical Structures: Trees, Binary Search Trees (BST)



Graph Structures: Adjacency lists, adjacency matrices, graph traversals



### **Advanced Topics**



Searching Algorithms: Linear and Binary Search



Recursion in Data Structure Operations





### **How to Use**



Each project folder is self-contained and includes its own documentation.

You can explore and run each implementation independently to study specific data structures or algorithms.
